# PowerBI em 7 Dias

## 📊 Projeto de Estudos - Power BI (Curso 7 Dias)

Este repositório reúne os dashboards e análises desenvolvidos durante o curso intensivo de 7 dias de Power BI, explorando diferentes fontes de dados e aplicando conceitos de visualização e análise.

### Objetivo 🎯

O projeto tem como finalidade praticar:

- Conexão com múltiplas fontes de dados.

- Transformação e tratamento de dados no Power BI.

- Criação de dashboards interativos no Power BI.

- Exploração de insights a partir de cenários reais.

### Fontes de dados exploradas 📂

- 📦 E-commerce – vendas e comportamento de clientes.

- 🎮 Jogos de PS4 – dados de vendas globais.

- 🌍 População mundial – evolução e distribuição por países.

- E outras bases disponibilizadas no curso.

### Ferramentas utilizadas 🛠️

- Power BI Desktop

- DAX (Data Analysis Expressions)
